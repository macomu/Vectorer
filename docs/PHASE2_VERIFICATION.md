# Phase 2 実装・検証結果

Phase 2 のインタラクティブキャンバス、描画・編集ツール、関連メニューの基礎実装と仕上げを完了しました。UI_DESIGN.md は Phase 3 の詳細パネルまで含む完成時仕様のため、この文書でフェーズ境界と検証範囲を明示します。

## 実装範囲

| 領域 | 実装内容 |
| --- | --- |
| ツール | 選択/変形、ノード、四角形、楕円/円弧、多角形/星形、フリーハンド、ベジェ/直線ペン、テキスト、パン。ツール状態は App.Tools へ分離 |
| ノード編集 | 点・ハンドルの移動、複数/範囲選択、座標入力、線分の分割・追加・削除、コーナー/スムーズ/対称、直線/曲線化、開閉、結合、切断、単純化 |
| パス結合 | 同一パスの選択端点、および同じ親に属する複数Pathの最寄りの開いた端点。変形・別輪郭・背面側のスタイルを保持し、Undoで順序も復元 |
| 単純化 | 適応分割から三次ベジェを最小二乗で再フィット。誤差が大きい区間は再分割し、端点・鋭い角・開閉・複数輪郭を保持 |
| オブジェクト | コピー/切り取り/貼り付け、複製、選択、グループ化/解除、階層内編集、重ね順、整列、等間隔分布、数値変形・反転・傾斜 |
| スタイル | 選択と規定値の同期、混在表示、変更属性だけを一括適用、色パレット/コード、塗り/線なし、線種。パラメトリック再編集と専用ハンドル |
| 文書/レイヤー | 新規プリセット、SVG入出力、文書設定、未保存確認、保存失敗保護。レイヤー追加/複製/削除/順序/表示/ロック/合成/変形/下と結合 |
| 表示/入力 | 10〜3200%ズーム、フィット、パン、グリッド、頂点/境界スナップ。テキスト/数値欄を優先するショートカットと段階的なEsc |
| UI | 自作SVGアイコン11種類、主要パラメータ入力、詳細項目の `⋯`、スクロール可能なインスペクタ。幅不足時は主要入力を横スクロールして利用可能 |

文書を変更する操作は Undo/Redo を通します。変形/描画中のプレビューをキャンセルした場合は履歴を追加しません。コピーの失敗時には切り取りを実行せず、保存先キャンセル・書き込み/フラッシュ失敗時には未保存状態を維持します。

| パス | パス変換、ストローク変換、5種類の論理演算、開閉、端点結合、単純化 | — |
| レイヤー | 追加/複製/削除、順序、表示/ロック、合成、変形、下と結合。任意角度は詳細設定から適用 | 階層ツリー、ドラッグ並べ替え、回転ダイアログの中心選択・ライブプレビュー |

主要キーは V/S・N/A・R・E・Y/*・P・B・T・H。編集は Ctrl+X/C/V/D/A/Z/Y、グループは Ctrl+G / Ctrl+Shift+G、パス変換と論理演算は UI_DESIGN.md の Ctrl+Shift 系を使用します。Ctrl+= / Ctrl+- は選択状態や図形を変えず表示倍率だけを変更します。数値・文字入力中はそのコントロールがキー入力を優先します。

## 性能確認

`LargeDocumentPerformanceTests` で5,000個の四角形、1,000×500 px、SVG約624 KBを生成し、往復保存・描画結果・スナップを検証しました。テストは計測値を出力しますが、機種依存の時間を合否条件にしません。

| 処理 | 当環境での計測例 |
| --- | ---: |
| SVGシリアライズ | 17.79 ms |
| SVG読み込み | 60.30 ms |
| 描画（ウォームアップ後3回平均） | 18.62 ms |
| スナップ候補構築 | 7.27 ms |
| プレビュー中のスナップ（100回平均） | 1.37 ms |

プレビュー中はスナップ候補を再利用し、確定・Undo/Redo・外部からの通常の再描画要求で破棄します。上記は単純図形の測定であり、複雑なフィルタ・シェーダー・長いパスで同じ速度を保証するものではありません。

## SVG・テキストの対応範囲

- 検証済み: 非ゼロ原点のviewBox、meet/slice/none、入れ子のアフィン変形、親からの塗り・線・フォント継承、インラインstyle、標準の色名・currentColor、空白区切り頂点列、複数行/日本語文字列の保存復元、フォント名・太字/斜体・字間・配置の保持。
- テキスト表示とパス変換はローカルにあるフォントのグリフ輪郭を使用します。任意の複雑な文字組み・書字方向・フォント埋込み・tspan単位の異なる書式・外部CSSの完全な互換性は対象外です。
- SVG円弧をノード編集モデルへ取り込む際は分割近似を行います。多角形の個別頂点編集はFreeformの直線頂点として保持し、ベジェ制御点が必要な場合はオブジェクトをパスに変換します。

画面操作ではベジェの連続入力、テキストの確定/取消、色パレット、ノード切替・頂点移動・数値入力、Undo、編集メニュー、文書設定ダイアログを確認しました。

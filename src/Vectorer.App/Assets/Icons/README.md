# 描画ツールの SVG アイコン

Vectorer 用に作成したオリジナルのアイコンです。プロジェクトと同じ MIT ライセンスで配布します。

24 × 24 の viewBox、塗りなし、単一の path、線幅 1.6、丸い線端・線結合で統一しています。`Controls/ToolIcon.cs` はこの path の `d` 属性を Avalonia の Geometry としてキャッシュし、表示サイズに合わせて描画します。外部 SVG ライブラリは使用しません。

アイコンを変更する場合は、図形を単一 path にまとめてください。画像埋め込み、テキスト、CSS、グラデーション、SVG transform はこのアイコン用コントロールでは解釈しません。通常の SVG エディタではそのまま表示・編集できます。

ノード編集 (`node.svg`)、ベジェペン (`bezier.svg`)、テキスト (`text.svg`) を含む計11種類を収録しています。
